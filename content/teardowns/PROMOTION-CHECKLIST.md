# Promotion and weekly measurement

- [ ] Human review and repository PR approval are complete.
- [ ] The reviewed page is live at its canonical URL and indexable. Never promote a draft preview as published work.
- [ ] Prepare one LinkedIn company-page post: sharpest finding, one line on the lesson, no URL in the post body.
- [ ] Put the teardown URL in the first comment after the post is live.
- [ ] Schedule no more than one teardown post per day; spread 2–3 across the week.
- [ ] Append actual publication/promotion outcomes to `_weekly-log.md`. A prepared post is not a posted one.
- [ ] Record only measurements available in existing consented analytics. Use “not available” for unmeasured page/transition attribution. Do not invent zeroes, create trackers/events, or imply site-wide shred counts came from a teardown.

A pipeline script never posts or publishes. Publishing and promotion remain separate human-reviewed actions.
