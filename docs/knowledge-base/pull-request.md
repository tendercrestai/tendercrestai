# Add secure organization knowledge base behind a disabled flag

TenderCrest currently stores user-owned RFPs but has no shared, organization-scoped evidence library. This adds Feature 1: private PDF/DOCX/TXT uploads, bounded background extraction and embeddings, pgvector search, and human-written approved answers with exact source citations. Editing an answer clears approval; archiving its source removes dependent answers from retrieval.

The additive migration introduces organization roles, RLS, immutable private storage, durable jobs, usage admission and metadata-only audit logs. A separate /knowledge.html workspace is disabled by default and unlinked from existing navigation. Existing billing, trial, reservations, submissions, contact forms, Airtable and Resend behavior are unchanged. Features 2–5 remain a documented incremental roadmap.

Validation: 114 Node tests pass (95 existing +19 KB); local PostgreSQL/pgvector migration and isolation/lifecycle suite pass (30 named assertions plus negative checks); 12 offline Chromium scenarios pass; static build, local packaging of all 11 functions and diff whitespace checks pass. The owner subsequently authorized isolated hosted tests: the test migration and deployment, real Auth/Storage, worker dispatch/integrity/retry limits, natural session expiry and browser refresh passed. Real TXT/PDF/DOCX indexing and baseline semantic search succeeded after enabling the model. The refreshed isolated branch key passed a direct embedding check. A Netlify alias/branch routing collision required a separate `kb1` branch preview; its runtime verification awaits environment network-policy publication. Stable hosted AI access and the complete browser upload/search flow remain gates. Provider access/quota errors now return actionable sanitized responses. Versioned approvals, stale conflicts, archival invalidation and real browser review/download passed. The additive conflict migration uses PT409 instead of retryable serialization_failure to return stale-edit conflicts promptly. No production changes were made.
