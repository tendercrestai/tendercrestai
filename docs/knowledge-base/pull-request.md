# Add secure organization knowledge base behind a disabled flag

TenderCrest currently stores user-owned RFPs but has no shared, organization-scoped evidence library. This adds Feature 1: private PDF/DOCX/TXT uploads, bounded background extraction and embeddings, pgvector search, and human-written approved answers with exact source citations. Editing an answer clears approval; archiving its source removes dependent answers from retrieval.

The additive migration introduces organization roles, RLS, immutable private storage, durable jobs, usage admission and metadata-only audit logs. A separate /knowledge.html workspace is disabled by default and unlinked from existing navigation. Existing billing, trial, reservations, submissions, contact forms, Airtable and Resend behavior are unchanged. Features 2–5 remain a documented incremental roadmap.

Validation: 114 Node tests pass (95 existing +19 KB); disposable PostgreSQL/pgvector migration and lifecycle suite passes (30 named assertions plus negative checks); 12 offline Chromium scenarios, static build and function packaging pass. Authorized isolated hosted testing verified real Auth/Storage, TXT/PDF/DOCX extraction and embeddings, private originals, role/RLS isolation, durable worker limits, natural session expiry/refresh, exact-revision approvals and source archival. After correcting the test credential and branch routing, all 11 final live retrieval assertions, 14 browser-flow assertions and six fresh-source/draft-retrieval assertions passed. The temporary diagnostic was removed. Production's published deploy is unchanged. Authorized production setup subsequently staged Production-only KB credentials with KB_ENABLED=false; no production migration, merge, deployment or activation has occurred. Detailed evidence and historical failures are in docs/knowledge-base/hosted-validation.md.
