# Learning and conversion release scope

User requested winning-bid training, win-probability predictions and global conversion analytics. Production audit: one fictional project, zero recorded outcomes, zero independently verified win/loss outcomes. The reference library has four guidance/prototype snapshots, not a verified reusable full winning-response corpus. Existing private company sources and approvals are not consent for shared model training.

Implement real consent-based first-party conversion analytics using existing Supabase/Netlify. Administrator selected private Supabase reports, with no new website access grants. Browser demo/signup intent is distinct from server-verified account, workflow and Stripe payment milestones. No proposal text, email address, full URL/referrer, search text, document name or payment identifier in analytics reports. Server-private account association enables deduplication/consent withdrawal; this is pseudonymous data, not an anonymous-data guarantee. No new paid analytics vendor.

Implement auditable training-data preparation and probabilistic-model evaluation tooling, with default abstention in the workspace. No fine-tuning job or real win probabilities can be released without eligible data, rights, verified outcomes (including losses), pre-submission predictors, independent held-out validation and reviewed provider cost/access. Synthetic tests must never become production training or evidence of calibration. Paid training requires a concrete budget/provider review. Do not relabel fit/readiness scores as probabilities.
