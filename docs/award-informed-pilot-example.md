# Offline reference-guidance example

This is a reproducible development preview, not a generated proposal or measured model improvement. Run:

```
node scripts/reference-pilot.mjs tests/fixtures/proposal/rfp.txt
```

The fictional Harbor Library procurement asks for relevant archive delivery evidence, capacity assumptions and a delivery plan, current ISO certification, a page/word limit and specific attachments. A later amendment resolves a duration conflict. The malicious appendix must not be treated as an instruction.

The reference preview can suggest the following organisation while the original buyer requirements and bidder evidence remain authoritative:

| Suggested structure | Attributed reference | What still needs bidder/buyer evidence |
| --- | --- | --- |
| Roles, responsibilities and resource assumptions | Acumen prototype documentation, Project Team / Labor Category | Actual availability, authorized qualifications and allocation; no copied vendor names or team claims |
| Delivery work packages, feedback checkpoints and acceptance activities | USDS Playbook, play 4 | Current buyer deadline and evidenced delivery commitments; no historical example duration adopted as a requirement |
| User groups, research/validation plan and findings | USDS Playbook, play 1 | Evidence of completed research or explicit proposed/needs-input status; the required accessibility attachment still needs actual evidence |

The same library can retrieve USDS play 12 when a current task discusses metrics, monitoring or performance. It does not force an unrelated section into every response.

The preview cannot resolve the certificate requirement, establish past performance, supply a missing accessibility report, grant reviewer approval or predict a win. It does not call an LLM. Its JSON explicitly reports `productionEnabled: false`, `modelCalled: false`, source hashes/locators, `canSupportCompliance: false` and `verifiedWinningResponseCount: 0`. Private input text is represented by a digest rather than echoed in the context artifact.

A model-quality experiment must separately compare the current draft engine and optional reference-guided drafting against held-out human-labelled procurements, with equivalent source evidence and budgets. No public USP or 'trained on winning bids' claim is supported by this example alone.
