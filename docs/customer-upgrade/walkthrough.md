# Customer experience walkthrough

The embedding-access blocker has been resolved: fresh fictional knowledge indexing and the complete reviewed export/reuse journey passed. Production rollout status is recorded in production-release.md.

1. Open TenderCrest and choose **Try Interactive Demo — No Credit Card Required**. No signup, upload or provider call occurs.
2. Select IT services, marketing or consulting. Inspect fictional RFP/profile/evidence, illustrative bid fit and strategy, source-referenced compliance gaps, then the six-part proposal preview. All content is labeled fictional/precomputed.
3. Choose **Create Free Account**. Existing Supabase signup and verification remain unchanged; signing in returns to the workspace. A paid plan's **Start Free Trial** CTA goes to existing pricing/Stripe terms: card required, 14 days, selected allowance, automatic billing unless canceled.
4. Create an organization in the existing Knowledge Library if needed, create a private project, save its company profile and follow the saved onboarding checklist. Upload authorized company documents through existing ingestion/consent. Ready sources, saved RFP and proposal text drive progress.
5. In **RFPs and Opportunities**, upload PDF/DOCX/TXT, review extraction (including scanned/partial warnings), consent to existing analysis, then explicitly share the reviewed snapshot with project members.
6. Review requirements and match approved current organization answers in existing Requirements/Evidence controls. In **Bid Intelligence**, the owner-manager records documentary references or clearly labeled human inputs, adjusts five weights totaling 100, and generates the strategy.
7. Inspect mandatory disqualifiers, missing information, capabilities, risks, case studies, proposed themes, evaluation approach and prioritized actions. Record a human pursue/review/pass decision with explanation. Download the inspectable JSON report. The score is not a chance of winning.
8. In **Proposal Studio**, generate a whole-proposal preview from accepted evidence and the saved RFP structure. Explicit manager acceptance replaces sections and resets review. Missing facts remain placeholders. Edit/autosave individual sections; optional regenerate/clarify/shorten/expand sends only the selected saved section and accepted excerpts to the existing model with explicit consent, then uses the existing preview/acceptance job workflow.
9. In **Compliance and Quality**, run the final audit. Inspect each mapping, supporting quotation, literal conflicting passage, missing attachment and outstanding approval. Resolve underlying requirements/evidence/text in their existing controls, obtain authorized review, render a draft if PDF pagination is needed and rerun the audit. Quality is an internal readiness measure, not a compliance certificate.
10. In **Exports**, download the existing branded DOCX/PDF/compliance/source-reference package from a saved revision. Enhanced final signoff requires a current audit without high/critical findings plus the existing readiness checks. Final buyer submission remains the customer's responsibility.
11. Save selected approved sections to the same organization knowledge base as draft answers, then approve them through the normal knowledge review workflow. Record a private self-reported outcome and feedback in Settings and Billing. No customer content is used for shared model training. Outcomes are not treated as independently verified award evidence.
