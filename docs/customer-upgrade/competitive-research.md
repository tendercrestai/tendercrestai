# Competitive research scope

Requested benchmark set: Loopio (loopio.com), Responsive (responsive.io), Inventive AI (inventive.ai), AutoRFP.ai (autorfp.ai), Arphie (arphie.ai), QorusDocs (qorusdocs.com), Tribble (tribble.ai), GovDash (govdash.com).

Current public documentation for these vendors could not be retrieved through this environment's configured network access. Loopio, Responsive, AutogenAI (earlier comparison) and GovDash requests failed through the normal proxy. Other unconfigured destinations were not bypassed. No verified contemporary capability comparison, market ranking, price comparison or competitive superiority claim is made.

The implementation benchmarks customer workflows, not copied vendor material: a low-friction demonstration, explainable bid decisions, evidence-backed quality review, approved organization knowledge reuse and editable proposal exports. Original TenderCrest design/components/code are retained. Before publishing any named competitor comparison, obtain current public product/security/pricing documentation for all eight vendors, retain URLs/dates, distinguish advertised features from independently tested functionality, and have the owner review the claims.
