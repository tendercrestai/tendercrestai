## Response format

- Point-by-point restatement: each numbered solicitation requirement is
  restated, followed by "Cisco Response:".
- No standalone compliance matrix and no "comply / does not comply" wording
  anywhere in the response.
- Mandatory items are marked (M) in sequence; the solicitation warns that a
  "no" response or an omission disqualifies the service from evaluation.
- Exceptions are confined to the terms appendices ("Noted Exceptions");
  none appear inline in the requirement answers.
- Pricing is a separate cost-schedule attachment (category minimum discounts
  and fully loaded hourly service rates), not a narrative section.

## Scope note

Single example: one 2013 US state/local IT procurement. This section order
does not establish what any other buyer expects.
